# Validation Rules

## Forms
Use Formik hooks for forms.

Use Yup for input validation.

## Schemas
Keep Yup schemas in separate files, outside components.

Schemas may live near the page feature.

Do not force all schemas into one global folder.

## Types
Keep interfaces and types in separate files, outside components.

Do this even if the type is only used by one component.

Types may live near the page feature.

Do not force all types into one global folder.
